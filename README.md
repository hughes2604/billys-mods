# Billy's Mods

A growing Fabric mod for Minecraft Java Edition **1.21.1**. It contains the Elixirs and Viltrumite Genome, with compatibility support for Ad Astra 1.16.26.

## Install

Use Minecraft **1.21.1**, Fabric Loader **0.19.5**, Fabric API **0.116.15+1.21.1**, and (for spaceflight compatibility) Ad Astra **1.16.26 for Fabric**. Download the JAR from the latest successful GitHub Actions build and place it in the Minecraft `mods` folder. See [installation instructions](docs/INSTALLATION.md).

## Features

- **Elixirs:** the Elixir of Immortality and Elixir of Mortality.
- **Viltrumite Genome:** carry it to gain strength, durability, flight, and four boost levels.
- **Ad Astra:** genome carriers do not need oxygen and can survive Ad Astra's space environments.

Ad Astra still controls its own planet travel and orbit transitions; the genome does not replace rockets or Ad Astra's destination selection.
