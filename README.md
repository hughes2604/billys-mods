# Billy's Mods

A small, growing Fabric mod for **Minecraft Java Edition 1.21.10**. It currently adds two elixirs and the Viltrumite Genome. Everything is grouped under one mod so new experimental features can be added over time.

## Get started

1. Make sure you have Minecraft Java Edition **1.21.10**, **Fabric Loader 0.19.5**, and **Fabric API 0.138.4+1.21.10** installed.
2. Open the [latest successful GitHub build](https://github.com/hughes2604/billys-mods/actions/workflows/build.yml). Choose the newest run marked successful.
3. In that run, find **Artifacts** and download the `billys-mods-...` ZIP file.
4. Open the ZIP and copy the `.jar` file inside into your Minecraft `mods` folder. Keep the JAR itself; do not put the downloaded ZIP in `mods`.
5. Start Minecraft with the Fabric profile.

You do not need to install a coding program or build the mod yourself. The download is produced remotely by GitHub Actions and is kept for 30 days. See [step-by-step installation help](docs/INSTALLATION.md).

## What is included

- **Elixirs** — drink the Elixir of Immortality to become immortal, and the Elixir of Mortality to become mortal again.
- **Powers** — carry the Viltrumite Genome to gain strength, durability, and flight.

Read [features and controls](docs/FEATURES.md) for details, or see the [changelog](CHANGELOG.md) for the Alpha update history.

## Multiplayer

For multiplayer, the server and every player joining it need Fabric, Fabric API, and Billy's Mods installed. The server handles the abilities and flight, while each player uses their own client controls.
